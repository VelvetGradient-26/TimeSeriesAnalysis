# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project

Time series analysis practice in Python, organized as numbered folders of Jupyter notebooks (for example, `1-Numpy/`). Keep new topics in their own numbered folder and add them to the table in `README.md`.

## Git conventions

- Remote: `https://github.com/VelvetGradient-26/TimeSeriesAnalysis.git`
- Main branch: `main`
- Commit messages are short: one or two lines, describing what changed and why.
- Never add `Co-Authored-By` lines (or any other AI attribution) to commit messages.
- Do not commit or push unless the user asks.
