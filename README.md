# TimeSeriesAnalysis

Learning notes and practice notebooks for time series analysis in Python, built up in stages.

## Contents

| Folder | Topic | Notebooks |
| --- | --- | --- |
| `1-Numpy/` | NumPy fundamentals | `1-basic.ipynb`, `2-indexing_selection.ipynb`, `3-array_operations.ipynb` |

### 1-Numpy

1. **basic**: creating 1D and 2D arrays, array attributes (`shape`, `dtype`, `ndim`), and common array methods.
2. **indexing_selection**: slicing, boolean selection, and broadcasting.
3. **array_operations**: element-wise arithmetic and vectorized operations.

## Requirements

- Python 3.9+
- [NumPy](https://numpy.org/)
- Jupyter (`jupyter notebook` or `jupyter lab`), or VS Code with the Jupyter extension

Install the dependencies:

```bash
pip install numpy jupyter
```

## Usage

Clone the repository and open the notebooks in order:

```bash
git clone https://github.com/VelvetGradient-26/TimeSeriesAnalysis.git
cd TimeSeriesAnalysis
jupyter lab
```
